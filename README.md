# Heleni tutvustusleht

Lihtne eestikeelne veebileht, mis tutvustab Helen Hütti ning tema hobisid ja huvisid.

**[Vaata veebilehte](https://h3ltz.github.io/portfolio/)**

## Lehe sisu

- Nimi ja lühike tutvustus
- Portreefoto
- Hobid: raamatute lugemine, ristsõnade lahendamine ja lauamängud
- Link [Heleni GitHubi profiilile](https://github.com/H3ltz)

## Kasutatud tehnoloogiad

Leht on loodud HTML5 ja CSS-iga. Kujundus kohandub nii arvuti kui ka telefoni ekraanile. CSS asub otse failis `index.html`; JavaScripti ega lisateeke pole vaja.

## Kohalik vaatamine

Laadi repositoorium alla ja ava `index.html` veebibrauseris. Portreefoto laadimiseks on vaja internetiühendust.

## Muutmine ja avaldamine

Teksti, pildi ja kujunduse muutmiseks redigeeri faili `index.html`. Salvesta muudatused GitHubis harusse `main`.

Veebileht avaldatakse GitHub Pagesiga haru `main` juurkaustast (`/`). Muudatuste salvestamisel uuendab GitHub Pages lehte automaatselt; avaldamise edenemist näeb repositooriumi vahekaardil **Actions**.

## Foto

Portreefoto tuleb praegu väliselt LinkedIni pildilingilt. Kui link aegub, tuleb pildi aadressi uuendada või lisada foto repositooriumi ja kasutada kohalikku failiteed.
